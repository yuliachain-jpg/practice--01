# API Testing in Postman

Учебный проект по проверке REST API в Postman.

## Что проверялось
- статус-коды (200, 201, 400, 404)
- тело ответа и структура JSON
- response time
- существующие и несуществующие ресурсы
- валидация данных

## Инструменты
Postman, REST API, JSON
